# Interlock Blueprint Package — Manifest

This package is a design/handoff artifact only. It contains no implemented app code, no real credentials and no deployment.

## Root files

- `INTERLOCK_IMPLEMENTATION_BLUEPRINT.md` — consolidated blueprint, fixed decisions, checklist and coding-agent start point.
- `PROJECT_SPEC.md` — product definition, MVP, roles, flows, requirements, state machines, edge cases and acceptance criteria.
- `ARCHITECTURE.md` — topology, trust boundaries, Walrus/Tatum/Sentinel/Runner contracts, security, auth and stack.
- `IMPLEMENTATION_PLAN.md` — autonomous Phase 0–9 plan with objectives, tasks, tests, acceptance and commits.
- `AGENTS.md` — persistent coding agent operating rules.
- `AI_HANDOFF.md` — exact current implementation state and next task.
- `OPERATOR_INTAKE.md` — one consolidated readiness check and authorization register.
- `REFERENCE_ASSETS.md` — honest record that no UI image is supplied and instructions for intake.
- `DEMO_VIDEO_PLAN.md` — story/script/capture/TTS/redaction/review requirements <=180 sec.
- `README.md` — project overview and handoff guide.
- `PROPER_VIBE_CODING_WORKFLOW_AUTONOMOUS.md` — supplied workflow reference copied into package.
- `MANIFEST.md` — this file.
